# DN·Gate — Умный въезд: маячок у шлагбаума, телефон — ключ

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon).  
Метка стоит у шлагбаума. Водитель подъезжает — приложение на смартфоне автоматически обнаруживает маячок и открывает проезд. Личный брелок не нужен.

## Сценарий

1. Метка DN·Gate смонтирована на столбе у въезда
2. Водитель подъезжает на расстояние ~10–30 м
3. Приложение DN·Gate (iOS / Android) обнаруживает BLE-сигнал
4. Сервер проверяет права водителя и посылает команду на контроллер шлагбаума
5. Шлагбаум поднимается, факт въезда фиксируется с временем и id водителя

## Когда применять

- Парковки и склады, где у сотрудников есть смартфоны, но нет личных меток
- Временный доступ для подрядчиков и курьеров (разовые ссылки-приглашения)
- Несколько въездных ворот на одном объекте под управлением одного приложения

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Корпус | IP67, 70 × 40 × 20 мм |
| Батарея | ER14505H-LD, до 15–20 лет |
| Дальность | 5–70 м (регулируется TX power) |
| Интеграция | REST API → контроллер шлагбаума (реле / Wiegand / RS-485) |
