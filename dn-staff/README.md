# DN·Staff — Контроль персонала: доступ в зоны и наличие СИЗ

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon).  
Метка вшивается или крепится на каску, халат или комбинезон. Считыватели у входов в зоны автоматически фиксируют: кто вошёл, во что одет и есть ли на нём требуемое средство защиты.

## Ключевая механика

Метка на СИЗ выполняет две функции одновременно:
1. **Идентификация** — кто именно вошёл в зону (конкретный сотрудник)
2. **Подтверждение наличия СИЗ** — если метка на каске обнаружена, значит каска надета

Считыватель у входа в опасную зону может потребовать одновременного наличия метки каски И метки комбинезона. При отсутствии любой из них — проход заблокирован, оповещение ответственному.

## Сценарии

- **Производственные предприятия** — вход в цех только в каске и комбинезоне
- **Медицинские учреждения** — вход в операционную только в халате и бахилах
- **Пищевые производства** — вход в чистую зону только в спецодежде
- **Строительные объекты** — вход в зону производства работ только в каске и жилете
- **Лабораторные комплексы** — контроль наличия СИЗ по классу опасности зоны

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Исполнение | нашивка / вшитый карман / клипса на каску |
| Корпус | IP54–IP67 в зависимости от исполнения |
| Батарея | CR2032 (компактная) или ER14505H-LD, до 3–15 лет |
| Дальность | 1–10 м у входа (настраивается) |
| Интеграция | REST API → СКУД / MES / система охраны труда |
