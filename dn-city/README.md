# DN·City — Платформа навигации и информирования пассажиров

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon) для идентификации остановок общественного транспорта, доступной среды и анализа пассажиропотока.

## Что решает

- **Точная идентификация остановок** — BLE-метка подтверждает нахождение транспортного средства у конкретной остановки даже при деградации GPS (плотная застройка, эстакады, туннели)
- **Доступная среда** — приложение для слабовидящих озвучивает номер маршрута и направление при подходе транспорта
- **Пассажирское информирование** — расписание, задержки и реклама доставляются на смартфоны ожидающих
- **Аналитика пассажиропотока** — плотность BLE-устройств фиксирует загруженность маршрутов

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Корпус | IP67, 70 × 40 × 20 мм |
| Батарея | ER14505H-LD, до 15–20 лет |
| Дальность считывания | до 70 м |
| Интервал передачи | настраиваемый |
| Рабочая температура | −40°C … +85°C |
| Интеграция | БНСО, РНИИС, мобильные приложения iOS/Android |

## Состав лендинга

`index.html` — одностраничный лендинг для продажи решения городским транспортным предприятиям, региональным операторам перевозок и муниципальным заказчикам.
