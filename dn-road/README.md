# DN·Road — Система контроля дорожных работ и инфраструктурной навигации

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon) для мониторинга дорожно-строительной техники и навигации в туннелях, подземных паркингах и закрытых объектах инфраструктуры.

## Что решает

- **Контроль дорожных работ** — катки, асфальтоукладчики и грузовики идентифицируются системой мониторинга; фиксируется количество проходов катка, время работы, принадлежность к участку
- **Навигация в туннелях** — сеть BLE-меток заменяет GPS внутри тоннелей и обеспечивает точную маршрутизацию
- **Навигация на подземных паркингах** — система указывает путь к свободному месту без спутникового сигнала
- **Контроль въезда/выезда тяжёлой техники** — автоматическая фиксация начала и конца смены по BLE-идентификатору

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Корпус | IP67, 70 × 40 × 20 мм (для техники — виброзащищённый кронштейн) |
| Батарея | ER14505H-LD, до 15–20 лет |
| Дальность считывания | 2–70 м (регулируется мощностью TX) |
| Рабочая температура | −40°C … +85°C |
| Интеграция | REST API → системы мониторинга дорожных работ, навигационные приложения |

## Состав лендинга

`index.html` — одностраничный лендинг для продажи решения дорожно-строительным организациям, операторам туннелей, управляющим компаниям паркингов и муниципальным заказчикам.
