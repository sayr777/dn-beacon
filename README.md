# DN·Beacon — Портфолио решений на базе динамической BLE-метки

Коммерческие решения на базе промышленного образца [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon) — автономной BLE-метки с динамически изменяемыми идентификаторами и сроком службы батареи до 20 лет.

## Аппаратная платформа

| Параметр | Значение |
|---|---|
| Чипсет | nRF52832 (модуль YJ-16013) |
| Формат сигнала | iBeacon (стандарт Apple/Google) |
| Корпус | AK-W-70-4, IP67, 70 × 40 × 20 мм |
| Батарея | ER14505H-LD (Li-SOCl₂, 2700 мАч) |
| Срок службы батареи | **15–20 лет** |
| Ток (день / ночь) | 5.2 µА / 1.1 µА |
| Интервал передачи | 2 с (день), 60 с (ночь) |
| Защита идентификатора | AES-128 ECB, смена каждые 5 мин |
| Дальность | до 70 м (регулируется) |
| Рабочая температура | −40°C … +85°C |
