Почему DN·Beacon

Ключевые свойства платформы, которые делают её пригодной для промышленного применения.

🔋

Батарея на 20 лет

Ток потребления 5.2 µА позволяет установить метку и забыть об обслуживании на весь срок эксплуатации объекта.

🔐

Нельзя скопировать

Идентификатор меняется каждые 5 минут по AES-128. Перехваченный сигнал устаревает быстрее, чем его успевают использовать.

🌧️

IP67 для улицы

Корпус AK-W-70-4 выдерживает прямое воздействие осадков, пыли строительной площадки и уличных условий.

📡

Стандартный iBeacon

Любой BLE-совместимый смартфон, бортовой трекер или сканер считывает метку без специального оборудования.

🔗

Открытый REST API

Сервер идентификации публикует JSON API. Интеграция с TMS, WMS, РНИС, 1С и любой платформой — за часы, не месяцы.

🏭
