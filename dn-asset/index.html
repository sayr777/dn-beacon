Принцип работы

Как работает мониторинг активов

Метка на каждом активе

DN·Asset крепится на контейнер, паллет, инструмент или единицу техники. Внутри — акселерометр I2C, который фиксирует движение и смену ориентации. IP67, работает при −40°C…+85°C.

BLE-шлюзы по периметру

Шлюзы на воротах, въезде, в складских секциях получают сигналы всех меток. Координата актива определяется по зоне шлюза с наилучшим RSSI. Покинул периметр — алерт немедленно.

Акселерометр: движется или нет

Метка сообщает: «я двигалась», «я повернулась», «я не двигаюсь N часов». Экскаватор простаивает больше заданного порога — диспетчер видит предупреждение ещё до звонка от подрядчика.

Алерт и история перемещений

Нарушение правила (нет движения/выход из зоны/потеря связи) → алерт в Telegram или email. История: где был актив каждый час за последние 90 дней. Для споров с арендаторами и подрядчиками.

Интеграция с ERP/WMS

REST API → 1С, SAP, Oracle WMS. Статус актива отображается в карточке номенклатуры. Отгрузка из WMS автоматически создаёт задачу «проверить, что актив у ворот».

Применимые требования

  • ГОСТ Р ИСО/МЭК 24730-5-2014 — RTLS CSS-радиоинтерфейс 2.4 ГГц. Применимо к BLE-позиционированию активов.
  • ГОСТ Р ИСО/МЭК 24730-1-2017 — RTLS API для интеграции с WMS/ERP.
  • ГОСТ 28906-91 (ИСО 8583) — форматы данных для систем инвентаризации.
  • ГОСТ Р ИСО/МЭК 18000-6-2013 — Радиочастотная идентификация UHF 860–960 МГц (EPC Gen2). BLE-метки DN·Asset совместимы с WMS, ориентированными на RFID по этому стандарту.
  • ГОСТ Р ИСО 17363-2010 — Применение RFID в цепи поставок. Контейнеры грузовые. DN·Asset интегрируется с системами, соответствующими этому стандарту.

Ключевые преимущества DN·Asset

Замена импорту

После 2022 г. nRF52832 доступен через Chipdip и Компэл. Вся производственная цепочка — отечественная.

AES-128 rolling ID

Estimote и Kontakt.io вещают статический UUID — клонируется за 30 сек. DN·Asset меняет подпись каждые 5 мин.

10 лет без обслуживания

GPS-трекеры — SIM + батарея 1–2 года. DN·Asset — без SIM, без замены батареи 10 лет.

IP67, −40°C…+85°C

Морозильный склад, открытый двор, горячий производственный цех — работает без ограничений.

10 лет без обслуживания

ER14505H-LD Li-SOCl₂ 2700 мАч: нет плановых замен батарей, нет простоев на обслуживание. AirTag — замена каждый год, тысячи тегов = тысячи выездов техника.

AES-128 против кражи

Rolling ID: каждые 5 минут UUID меняется. Нельзя клонировать тег, нельзя отследить маршрут актива по перехваченному радиосигналу — данные защищены аппаратно.

Открытый стандарт

Стандартный iBeacon/Eddystone — работает с любым BLE-шлюзом, любым смартфоном. Zebra ZB200 привязывает к проприетарным ридерам, Apple — к iOS-устройствам.

Импортозамещение

Нет зависимости от Apple/Zebra — обе компании под рисками импортных ограничений. nRF52832 доступен через отечественных дистрибьюторов.
