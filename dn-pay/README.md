# DN·Pay — Система бесконтактного контроля доступа и оплаты проезда

Лендинг решения на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon) для автоматической безбарьерной оплаты проезда.

Исходный код проекта: [github.com/sayr777/ble-transit-payment](https://github.com/sayr777/ble-transit-payment) (приватный).

## Что решает

- Безбарьерный вход в транспорт — пассажир проходит без касания, турникет открывается по BLE
- Криптографически защищённый билет — AES-128, динамический идентификатор нельзя скопировать
- Офлайн-валидация на турникете без постоянного соединения с сервером
- Единая метка для автобуса, трамвая, метро и парковки
