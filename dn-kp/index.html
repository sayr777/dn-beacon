Процесс

Как строится коммерческое предложение

Четыре шага от задачи до подписанного договора и работающего пилота.

1 📋

Описание задачи

Заказчик описывает контур: количество объектов, тип отслеживаемых активов, требуемые интеграции (TMS, WMS, 1С, РНИС, АСОП). Достаточно письма в свободной форме.

2 🏗️

Архитектурное решение

Подбирается конфигурация: какой продукт DN·* закрывает задачу, сколько нужно меток, BLE-шлюзов и серверных компонентов. Схема данных и точки интеграции.

3 💰

Расчёт стоимости

Фиксированная стоимость пилота + масштабируемая цена тиража (за единицу оборудования). ROI-модель в Excel по запросу.

4 🤝

Подписание и старт

NDA по запросу. Договор поставки оборудования + договор сопровождения. SLA фиксируется в приложении к договору. Пилот стартует через 1–2 недели после подписания.

Типовые сценарии

Реальные конфигурации для разных типов заказчиков — отправная точка для вашего КП.

🚚

Транспортная компания

200 прицепов · DN·Fleet · Wialon

Метки на прицепах, считыватели на тягачах или на воротах склада. Интеграция с Wialon: факт сцепки/расцепки, зона нахождения прицепа, уведомления при несанкционированном движении.

Строительный подрядчик

50 объектов · DN·Staff + DN·Rent · 1С

Метки на касках и инструменте. Контроль СИЗ при входе в зону, инвентаризация оборудования через смартфон, интеграция с 1С: ведомость присутствия и журнал выдачи инструмента.

🚌

Городской транспорт

500 маршрутных ТС · DN·Pay · АСОП

Брелоки-метки для пассажиров. Валидаторы на входных дверях автобусов. Офлайн-валидация, интеграция с региональным АСОП через REST API, поддержка льготных тарифов.

🏭

Промышленное предприятие

3 цеха · DN·Man + DN·Mesh · автономная сеть

Метки на работниках в зонах без WiFi. Mesh-сеть из ретрансляторов — единственный BLE-шлюз у выхода. Детектор падения + SOS-кнопка. Полностью автономно, без внешних IP-адресов.

Ценообразование

Модель стоимости

Три уровня входа — от пилота одного маршрута до партнёрской программы для системных интеграторов.

Пилот

Пилотный проект

Фиксированная стоимость, ограниченный масштаб. Всё необходимое для оценки ROI и принятия решения о тиражировании.
  • Ограниченный контур (1 маршрут / 1 объект / 1 цех)
  • Срок: 2–4 недели от подписания
  • Фиксированная цена — без сюрпризов
  • Полный стек: метки + шлюзы + сервер + API
  • Интеграция с одной внешней системой
  • Отчёт по итогам пилота с рекомендациями
Тираж

Промышленный тираж

Масштабируемая модель: цена за единицу оборудования снижается с объёмом. Два варианта лицензирования ПО.
  • Цена за метку — снижается от объёма
  • ПО: годовая лицензия или self-hosted (без абонплаты)
  • Поэтапный ввод в эксплуатацию без остановки
  • SLA 99,5% uptime сервера
  • OTA-обновления прошивки включены
  • Поддержка 24/7 по критическим инцидентам
Партнёрам

Партнёрская программа

Для системных интеграторов транспортного мониторинга, автоматизации логистики и промышленной безопасности.
  • Партнёрская скидка на оборудование
  • Полная техническая документация и SDK
  • Обучение инженеров и pre-sales
  • Совместные пресейлы по запросу
  • Приоритетная техническая поддержка
  • White-label опция — по согласованию
