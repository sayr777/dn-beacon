Знак не горит — патрульный автомобиль узнает при проезде

DN·Sign — BLE-модуль в корпусе активного дорожного знака. Транслирует телеметрию: статус LED, заряд аккумулятора, температуру. Патрульное ТС или дорожная служба считывает данные без остановки. Неисправность фиксируется автоматически — не ждать ежеквартального объезда.

Проблемы отрасли

Активный знак, который никто не контролирует

Активные дорожные знаки — дорогостоящие объекты стоимостью 50–500 тыс. рублей каждый. Но их техническое состояние выявляется только при ручном объезде.

Знак не горит — неделю никто не знает

Аккумулятор разряжен или контроллер LED завис. Водители не видят рекомендуемую скорость или предупреждение о пешеходном переходе. Инспекция узнаёт при следующем объезде.

Зима убивает аккумуляторы

Солнечные батареи не заряжают в декабре–феврале. Аккумулятор деградирует в мороз. Самые критичные для зимней дороги знаки — самые уязвимые в самое опасное время года.

Нет журнала ТО для КЖЦ

Контракт жизненного цикла требует документирования технического обслуживания. Ручные записи объездных бригад — неполные и с запозданием. DN·Sign создаёт автоматический журнал.

Временные знаки: нет учёта установки

Подрядчик установил временный знак ограничения скорости на ремонте. Знак сдвинули, убрали — никто не фиксирует. При ДТП в зоне работ доказать факт установки невозможно.

Принцип работы

Как DN·Sign передаёт телеметрию знака

BLE-модуль в корпусе знака

DN·Sign встраивается в корпус активного знака рядом с контроллером LED. Подключается к контроллеру по UART/I2C — считывает статус LED, уровень заряда аккумулятора, температуру внутри корпуса.

Непрерывная трансляция телеметрии

Метка транслирует iBeacon-пакет с закодированной телеметрией: LED горит/не горит, заряд 0–100%, температура °C, uptime контроллера. Интервал передачи — настраиваемый.

Патрульное ТС считывает при проезде

BLE-считыватель в патрульном автомобиле дорожной службы фиксирует пакет при проезде мимо знака. Данные уходят на сервер через LTE автоматически. Машина не останавливается.

Сервер строит карту состояния

Каждый проезд — обновление статуса знака на карте. Алерты при разряде (<20%), отказе LED или аномальной температуре. Для редко объезжаемых участков — периодический плановый маршрут.

Автоматический акт ТО

При обслуживании бригада ТО сканирует метку знака — в журнале создаётся запись с временной меткой и геокоординатой. Документ готов для КЖЦ-контракта и дорожного аудита.

Данные при проезде, без остановки

Патрульный автомобиль объезжает маршрут в обычном режиме. BLE-считыватель автоматически «опрашивает» каждый знак при проезде. Инспектор не выходит из машины.

🔋

Предиктивное предупреждение о разряде

Система предупреждает о разряде заранее (<20% = предупреждение, <10% = критический алерт + автозаявка). Замена аккумулятора планируется, а не случается аварийно.

📋

Автоматический журнал КЖЦ

Каждый проезд и каждое ТО — запись в журнале с временной меткой и геопозицией. Документ соответствует требованиям контракта жизненного цикла знаков.

📡

V2I — предупреждение водителю

Опция: мобильное приложение водителя или бортовой блок принимает сигнал DN·Sign при приближении. Неисправный знак = предупреждение в навигаторе.

Интеграция

Открытый API для инфраструктурных платформ

АСУДД

Автоматизированные системы управления дорожным движением. Телеметрия знаков DN·Sign поступает в АСУДД через REST API, отображается на общей карте сети.

Wialon / СКАУТ

Патрульные ТС уже оснащены бортовыми блоками Wialon или СКАУТ. DN·Sign интегрируется через Bluetooth-модуль блока — данные знаков отображаются в той же системе мониторинга транспорта.

ГИС Росавтодора

REST API → ГИС-платформы федерального и регионального дорожного хозяйства. Актуальный реестр состояния знаков по трассе — без ручного ввода.

Система ТО

Автоматическое создание заявок на ТО при срабатывании алертов. Интеграция с CMMS (Maximo, 1С:ТОиР) — заявка создаётся в нужной системе сразу при фиксации неисправности.

Сценарии применения

Любые активные объекты дорожной инфраструктуры

🛣️

Федеральные и региональные трассы

Сотни активных знаков на трассе. Ручной объезд раз в неделю — это слишком редко для объектов безопасности. DN·Sign даёт актуальный статус после каждого проезда патрульного ТС.

  • Автоматический учёт в реестре знаков
  • Соответствие требованиям Росавтодора к мониторингу
  • Предиктивное планирование ТО вместо аварийного
🚶

Умные пешеходные переходы

Знаки с радарными табло скорости, подсветкой разметки, светофорными секциями. Каждый элемент с DN·Sign сообщает о своём статусе — не только знак в целом.

  • Мониторинг радарного табло отдельно от знака
  • Алерт при отказе светодиодной подсветки
  • Статистика по времени неисправности для отчётов
🚧

Временная организация движения

Временные знаки на объекте дорожного ремонта. Подрядчик обязан установить — и DN·Sign фиксирует факт установки, снятия и рабочее состояние.

  • Электронный журнал установки/снятия временных знаков
  • Доказательная база при ДТП в зоне работ
  • Контроль соответствия схеме ОДД
🚇

Тоннели и знаки переменной информации

В тоннелях знаки переменной информации критичны. Отказ в тоннеле — нет естественного освещения, водители дезориентированы. DN·Sign + DN·Mesh обеспечивают мониторинг без GSM-покрытия.

  • Мониторинг при отсутствии мобильной связи
  • Интеграция с системами вентиляции и освещения тоннеля
  • Алерт в диспетчерскую тоннеля немедленно при отказе
