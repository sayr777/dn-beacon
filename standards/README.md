## Примечание о применении ISO 13000 и ISO/IEC 24730-5

Стандарт **EN 13000:2010+A1:2014** («Краны мобильные. Безопасность») применим к UWB-продукту **RTLS·Crane** (репозиторий `dn-rtls`), не к BLE-продуктам.

Стандарт **ISO/IEC 24730-5** (ГОСТ Р ИСО/МЭК 24730-5-2014) описывает CSS-радиоинтерфейс RTLS на 2.4 ГГц — ближайший по частотному диапазону к BLE, применим как обоснование RTLS-архитектуры на базе BLE при позиционировании в продуктах DN·Asset, DN·Staff, DN·Safe.
