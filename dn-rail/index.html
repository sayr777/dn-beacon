DN·Rail — два модуля для железнодорожной инфраструктуры. Первый: необходимое доказательство физического присутствия сотрудника у объекта — вместо фиктивных отчётов. Второй: бесшовная навигация по ТПУ и вокзалам для пассажиров там, где нет GPS.

Можно внедрять вместе или отдельно в зависимости от задачи.

Модуль 1

Контроль обходов инфраструктуры

Маячок на стрелочном переводе, опоре контактной сети, мостовом пролёте, трансформаторной будке. Обходчик со смартфоном обязан «отметиться» у каждой точки. Система фиксирует факт присутствия с точностью до метра — не просто «был в районе».

  • Фиктивный обход исключён: нужно подойти на <3 м
  • Временно́й штамп + ID сотрудника + GPS+BLE координата
  • Алерт диспетчеру: точка пропущена или посещена с опозданием
  • Автоматический наряд-допуск: закрывается при обходе всех точек
  • Отчёт для проверяющих — неизменяемый журнал
Модуль 2

Навигация по ТПУ и вокзальным комплексам

Крупные транспортно-пересадочные узлы — многоуровневые лабиринты подземных переходов, платформ и автовокзалов. GPS внутри не работает. BLE-маячки покрывают каждый коридор и обеспечивают пошаговую навигацию.

  • «Из вагона метро к платформе Сапсана» — один маршрут
  • Актуальные данные о задержках транспорта
  • Навигация для слабовидящих: голосовые подсказки
  • Аварийная эвакуация: маршрут к ближайшему выходу
  • Реклама магазинов и кафе по маршруту

🔒

Фиктивный обход невозможен

Маячок фиксирует присутствие только при физическом подходе ближе 3 метров. Нельзя «подписать» точку дистанционно, задним числом или из кабины дрезины.

🌨️

Работает в −40°C и IP67

Маячок установлен на открытой инфраструктуре. Промышленный корпус AK-W-70-4, батарея Li-SOCl₂ стабильна в экстремальных температурах.

📱

Обходчику — только смартфон

Никакого специального оборудования. Корпоративное приложение на Android-смартфоне считывает маячок в фоне. Сотрудник видит список точек и галочки по мере обхода.

⚡

Наряд-допуск закрывается автоматически

Все 14 точек пройдены → наряд закрывается в системе документооборота без ручного ввода. Инспектор видит неизменяемый журнал с криптографической подписью.

🚨

Аварийная сигнализация

Смартфон обходчика не регистрировал движение 15+ минут в опасной зоне — алерт диспетчеру. «Человек упал» определяется акселерометром телефона в связке с BLE.

Модуль 2 · Детали

Навигация на ТПУ: сценарии для пассажиров

Бесшовный маршрут там, где GPS не работает и пересадки занимают время.

🚇

Метро → электричка

На Курском, Ярославском, Белорусском — пересадки через подземные переходы. Маячки ведут пассажира от выхода из вагона до нужной платформы пригородного поезда без навигатора.

🚌

Вокзал → автобусная станция

Крупный вокзальный комплекс с несколькими уровнями и переходами. «Ваш автобус до Суздаля — выход C, 200 м прямо и налево, платформа 7».

♿

Доступность для маломобильных

Маршруты с учётом лифтов и пандусов, голосовые подсказки для слабовидящих. «Говорящий вокзал» — без специальных устройств напрокат.

🚨

Аварийная эвакуация

При эвакуации система переключается в режим «кратчайший путь к выходу». Пассажиры получают push-уведомление с маршрутом на свой смартфон.

📊

Аналитика трафика для ж/д оператора

Тепловые карты загруженности переходов, «узкие места» инфраструктуры, прогноз пиков для планирования персонала. Данные в реальном времени.

🏪

Коммерциализация пространства

Реклама магазинов и кафе по маршруту пассажира. Интеграция с DN·Promo — дополнительный доход для управляющей компании ТПУ.
