Одна метка — NFC и BLE одновременно

DN·Tap работает в двух режимах параллельно: BLE транслирует зашифрованный динамический маяк в фоне — для автоматического отслеживания присутствия. NFC отвечает на касание смартфоном — мгновенный URL, ID, действие. Один чип, два протокола, нет необходимости выбирать.

NFC и BLE — разные задачи

Почему нужны оба протокола

NFC требует намеренного касания — человек управляет взаимодействием. BLE работает пассивно — система видит присутствие без действий.

NFC — касание смартфона DN·Tap

  • Расстояние: до 4 см — физическое касание
  • Только умышленное действие человека
  • Статический ID/URL/контакт — не меняется
  • Не требует Bluetooth на смартфоне
  • Работает с любым NFC-смартфоном без приложения
  • Скорость: <1 секунды на передачу данных

BLE — фоновый маяк DN·Tap

  • Расстояние: до 70 м — без касания
  • Пассивное присутствие: система видит метку автоматически
  • Динамический ID: меняется каждые 5 мин (AES-128)
  • Читается шлюзами, нет необходимости в смартфоне
  • Постоянная трансляция: контроль местонахождения 24/7
  • Подходит для автоматизации без участия человека
Принцип работы

Как DN·Tap работает в двух каналах

Метка в покое — BLE маяк работает в фоне

Метка непрерывно транслирует iBeacon-пакет с динамическим зашифрованным ID. Шлюзы в помещении фиксируют присутствие и передают на сервер: объект здесь, вот его ID, вот RSSI.

Человек прикладывает телефон — NFC отвечает

NFC-чип nRF52832 хранит статическую запись: NDEF-URL, ID объекта, контакт. Смартфон считывает за <1 секунды. Не нужно приложение, не нужен Bluetooth — стандартный NFC Android/iOS.

Сервер сопоставляет оба канала

BLE говорит «объект находится в зоне B». NFC говорит «этот же объект только что просканировали в 14:22». Два независимых подтверждения одного факта — двойная верификация без дополнительного оборудования.

Действие — по любому каналу

Подошёл к двери — BLE открыл шлагбаум. Хочешь узнать детали — приложил телефон к NFC. Нужна двухфакторная авторизация — оба канала подтвердили личность. Логика на стороне сервера.

Гостиничный ресепшн без стойки

Бронирование подтверждено → BLE-браслет выдан. Гость подходит к номеру — BLE открывает дверь. Хочет узнать Wi-Fi или услуги — прикладывает телефон к NFC-табличке в комнате.

💊

Медицинский браслет пациента

BLE показывает, где находится пациент в отделении. Медсестра прикладывает сканер к браслету — NFC мгновенно открывает карту пациента в МИС. Без ввода ID, без ошибок.

🔧

Допуск к оборудованию

Рабочий подходит к станку — BLE видит наличие допуска. Нажимает «Пуск» — NFC-касание как второй фактор подтверждения. Без NFC-касания опасная операция не запускается.

📦

«Тап за деталями» на оборудовании

На каждой единице оборудования — DN·Tap. Любой сотрудник прикладывает телефон — открывается паспорт техники, последнее ТО, QR-инструкция. Без QR-кодов, без приложения.
