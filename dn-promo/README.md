# DN·Promo — Платформа геоконтекстной рекламы (Location-Based Advertising)

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon).  
Маячок у входа в магазин, на остановке, в торговом центре или аэропорту — точка геоконтекста. Когда смартфон пользователя оказывается рядом, платформа DN·Promo отправляет персонализированное предложение с точностью до конкретного стеллажа или зоны.

## Рынок

Глобальный рынок LBA (Location-Based Advertising) превысил **$15 млрд** в 2024 году и продолжает расти на 20%+ в год. iBeacon — основная технология proximity-маркетинга с точностью позиционирования 1–3 метра против ~50 метров у GPS-геофенсинга.

## Сценарии

- **Ритейл** — скидка при входе в магазин или у полки с товаром
- **ТРЦ** — навигация + контекстные предложения от арендаторов
- **Остановки ОТ** — реклама по маршруту и времени ожидания
- **Аэропорты и вокзалы** — duty-free, залы ожидания, навигация
- **Музеи и выставки** — аудиогид, доп. контент у экспонатов
- **HoReCa** — приветствие, меню, лояльность при входе в заведение
- **Спортивные арены** — заказ еды, повторы, мерч у нужной трибуны

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (совместим со всеми LBA SDK) |
| Корпус | IP67, 70 × 40 × 20 мм — для улицы и помещений |
| Батарея | ER14505H-LD, до 15–20 лет |
| Точность позиционирования | 1–3 м (по RSSI) |
| Интеграция | REST API → CRM / CDP / рекламные платформы |
