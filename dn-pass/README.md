# DN·Pass — Персональная метка водителя: автоматический въезд без телефона

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon).  
У каждого водителя или транспортного средства — личная метка. Считыватель у шлагбаума непрерывно сканирует эфир и открывает проезд при обнаружении авторизованной метки. Смартфон не нужен.

## Сценарий

1. Личная метка DN·Pass на брелоке или закреплена на транспортном средстве
2. Водитель подъезжает к шлагбауму
3. BLE-считыватель у ворот обнаруживает метку и расшифровывает динамический ID
4. Сервер DN·Pass идентифицирует водителя, проверяет права
5. Шлагбаум открывается автоматически, запись в журнале: кто, когда, в каком направлении

## Когда применять

- Корпоративные автопарки и гаражи: водитель вообще не тянется за телефоном
- Карьеры и промышленные объекты: смартфон запрещён по ТБ, метка на каске или кабине
- Многоворотные периметры: одна метка открывает все авторизованные ворота

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Вариант исполнения | брелок / карточка / накладная метка на ТС |
| Корпус | IP67, 70 × 40 × 20 мм (версия на ТС) |
| Батарея | ER14505H-LD, до 15–20 лет |
| Дальность | 1–50 м (регулируется) |
| Интеграция | REST API → контроллер шлагбаума (реле / Wiegand / RS-485) |
