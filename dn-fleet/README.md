# DN·Fleet — Система идентификации транспортных активов

Решение на базе BLE-метки [dynamic-iBeacon](https://github.com/sayr777/dynamic-iBeacon) для автоматической идентификации навесного оборудования, авторизации водителей и контроля грузов в коммерческом транспорте и логистике.

## Что решает

- **Идентификация «свой–чужой»** — прицепы, ковши, катки, цистерны автоматически распознаются бортовым трекером при сцепке
- **Авторизация водителей** — персональный брелок-метка подтверждает личность при посадке в кабину
- **Контроль грузов** — метки на паллетах и контейнерах фиксируют точное время погрузки/разгрузки

## Технические характеристики метки

| Параметр | Значение |
|---|---|
| Формат | iBeacon (AES-128, динамические Major/Minor) |
| Корпус | IP67, 70 × 40 × 20 мм |
| Батарея | ER14505H-LD, до 15–20 лет |
| Дальность считывания | 2–70 м (регулируется) |
| Рабочая температура | −40°C … +85°C |
| Интеграция | REST API → GPS-трекер / БНСО / TMS |

## Состав лендинга

`index.html` — одностраничный лендинг для продажи решения корпоративным заказчикам: компаниям с автопарком, экскаваторной и строительной техникой, логистическими терминалами.
