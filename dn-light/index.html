DN·Light vs классический Pick-by-Light

Нет кабелей — нет проблем с монтажом

Традиционные проводные pick-by-light системы требуют кабельной разводки к каждой ячейке. DN·Light работает по BLE — каждая метка автономна.

Проводной Pick-by-Light

  • Кабельная разводка к каждой ячейке
  • Монтаж 1000 ячеек — 3–4 недели
  • Жёсткая привязка к планировке склада
  • Переезд/реорганизация — новая проводка
  • Стоимость: 3 000–8 000 руб. за ячейку
  • Питание от сети 220В везде

DN·Light — беспроводной

  • BLE-метка на каждой ячейке — без проводов
  • Монтаж 1000 ячеек — 1 день (1 дюбель/ячейка)
  • Перестановка ячейки — снял и перевесил
  • Реорганизация склада — 2 часа в конфигураторе
  • Батарея 15–20 лет без замены
  • BLE-шлюзы — 1 на 50–70 ячеек
Принцип работы

Как WMS управляет светом в ячейках

WMS формирует задание на отбор

1С WMS, SAP EWM или любая другая система формирует задание: «паллет для заказа №4471 — ячейки A-3, B-7, C-12». Команды уходят через REST API на сервер DN·Light.

BLE-команда → шлюз → метка

Сервер через BLE-шлюз отправляет команду конкретным меткам: «включить жёлтый мигающий». Метка получает команду через BLE-соединение и активирует PWM на LED-индикатор.

Кладовщик видит — идёт к ячейке

Жёлтый мигающий свет указывает нужную ячейку. На дисплее или голосовом устройстве — количество. Кладовщик берёт товар — не думает, не ищет, не ошибается.

Кнопка подтверждения → зелёный → следующий

Нажал кнопку на метке — сигнал в WMS «взято». LED переключился в зелёный — задание по этой ячейке выполнено. Метка погасла. WMS автоматически подсветил следующую.

Красный — не берите! Пустая / неверная

WMS обнаружил расхождение — например, ячейка по факту пуста — метка зажигает красный. Кладовщик не берёт, вызывает кладовщика. Ошибка не уходит дальше по цепочке.

Три цвета — три состояния

Жёлтый мигающий = «бери здесь». Зелёный = «взято, молодец». Красный = «не бери, проблема». Никакого обучения — за 15 минут любой новый сотрудник работает без ошибок.

Фармацевтические склады

Ошибка комплектации → неверный препарат → угроза здоровью. Pick-by-light в фарме — отраслевой стандарт. DN·Light без кабелей ускоряет внедрение в 5 раз.

  • ~0% ошибок комплектации
  • GDP-совместимый лог операций
  • Интеграция с МДЛП/Честный знак

Автозапчасти и мелкоштучка

Тысячи SKU мелких деталей — номенклатура неотличима внешне. Pick-by-light исключает человеческий фактор при подборе похожих позиций.

  • Высокая скорость ротации
  • Мелкие ячейки — компактные метки
  • Интеграция с 1С:Торговля
👕

Мода, текстиль, e-com

Быстрый оборот SKU и частые планировочные изменения — именно то, где беспроводной pick-by-light даёт преимущество перед проводными аналогами.

  • Быстрая перепланировка
  • Сезонные ротации SKU
  • Интеграция с Ozon / WB API
🥫

Пищевое производство и FMCG

FEFO-принцип (first expired, first out) на складе: LED подсвечивает ячейку с ближайшим сроком годности — без сложных настроек в WMS.

  • FEFO / FIFO автоматически
  • Контроль сроков годности
  • Журнал для Роспотребнадзора
